# CYBERHUB – AI-Powered Public Digital Identity Intelligence System

## Project Purpose
CYBERHUB is an AI-powered intelligence system designed to gather, analyze, and synthesize public digital identity information. It helps visualize digital footprints, analyze public OSINT data points, and provide clear insights into public online presence while prioritizing privacy, security, and structured intelligence reporting.

## Current Technology Stack
- **Frontend**: React (JavaScript) + Vite, powered by `npm`
- **Backend**: Python 3 + FastAPI, served with `uvicorn`

## Project Status
**Foundation Initialized (Phase 1)**: The core repository structure (`frontend/`, `backend/`, `demo/`, `docs/`) and basic server foundations are set up. Both the React/Vite frontend and Python FastAPI backend health endpoints are ready for incremental feature additions.
